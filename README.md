# Wazuh–Shuffle–Telegram Security Alert Automation

## Overview

This project demonstrates the automation of Wazuh security alerts using
Shuffle SOAR and Telegram Bot integration.

The workflow receives security alerts generated by Wazuh, processes the
alert through Shuffle SOAR, extracts important alert information, and
automatically sends a formatted notification to a Telegram channel or chat.

This automation helps reduce manual alert monitoring and enables SOC analysts
to receive security notifications quickly.

## Workflow

### 1. Wazuh Alert Generation

Wazuh monitors endpoint and security events and generates alerts based on
configured detection rules.

Example alert information includes:

- Alert Title
- Severity
- Rule ID
- Timestamp
- Endpoint Information
- Security Event Details

### 2. Alert Forwarding

The Wazuh alert is forwarded to Shuffle SOAR through the configured
integration or webhook.

### 3. Shuffle SOAR Processing

Shuffle receives the Wazuh alert and processes the event.

The workflow extracts important fields such as:

- Title
- Severity
- Rule ID
- Timestamp

### 4. Telegram Notification

Shuffle sends the processed alert to Telegram using a Telegram Bot.

The final notification is formatted to provide SOC analysts with the
important information required for initial alert investigation.
